
# Sales Data Analysis Using Python and SQL

## Project Overview
This project analyzes a sample sales dataset using Python, Pandas, and SQL to identify revenue trends, top-performing products, and business insights.

## Objectives
- Calculate key sales performance metrics.
- Analyze monthly revenue trends.
- Identify products generating the highest revenue.
- Compare units sold with revenue.
- Develop data-driven business recommendations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- SQL
- GitHub

## Dataset
The project uses 20 synthetic sample sales records from January to May 2026.

Columns include order ID, order date, product, category, quantity, unit price, and region.

Note: This is a practice dataset, not real company sales data.

## Key Results
- Total Revenue: ₹719,700
- Total Orders: 20
- Total Units Sold: 121
- Average Order Value: ₹35,985
- Highest Monthly Revenue: May 2026 — ₹203,800
- Lowest Monthly Revenue: April 2026 — ₹80,800
- Top Revenue-Generating Product: Laptop — ₹495,000

## Business Insights
- Laptops generated the highest revenue among the five products.
- Mice had the highest unit sales, with 57 units sold.
- May recorded the highest monthly revenue.
- April recorded the lowest monthly revenue and may need further investigation.

## Project Files
- `data/sales_data.csv` — Sample sales dataset
- `sales_analysis.py` — Python data analysis
- `sql/sales_analysis.sql` — SQL analysis queries
- `reports/sales_insights.md` — Findings and recommendations

## Limitations
The dataset is small and synthetic. These findings are for learning and demonstration and should not be treated as actual business performance.
